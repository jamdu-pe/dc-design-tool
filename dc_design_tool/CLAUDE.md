# CLAUDE.md (패키지 내 사본)

운영 규칙 원본은 **프로젝트 루트의 `CLAUDE.md`** 이다. Claude Code가 실제로 읽는 파일은
루트 사본이므로, 규칙 변경은 루트 파일에서 한다.

- 절대 규칙(수치는 engine 호출, 카탈로그 밖 장비 금지, projected 표기, 고지문 삽입)
- 오케스트레이션 절차(intake → sizing → mechanical/electrical/ict → compliance → reporter)
- 엔진 API 표 및 빌드/실행 명령

→ 모두 `../CLAUDE.md` 참조.
